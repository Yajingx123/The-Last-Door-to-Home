------------------The Last Door to Home--------------------------

A short 2D narrative puzzle game with light horror and branching endings.

------------------------- How to Run--------------------------------

1. Unzip the submitted game build.
2. Open the unzipped folder.
3. Run the executable file:

`The Last Door to Home.exe`

The game is designed to be played with keyboard controls.


-------------------Key	Functions-------------------------

W/A/S/D		Move the player

Arrow Keys	Move the player / move between options

Enter		Confirm, interact with objects, open dialogue, continue dialogue, and select options

Tab			Open or close the inventory panel and view information about collected items

Esc			Open or close the pause menu


------------------------- Objective----------------------------

Explore the abandoned base as Kian, collect clues and items, understand what happened after the failed portal launch, and find the real way home.

The game includes multiple endings. The true ending requires careful exploration, correct item use, and confronting the final monster.

----------------------------Notes-----------------------------
