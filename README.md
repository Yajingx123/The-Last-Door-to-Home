# The Last Door to Home

## Module Information
**Module:** DI32002 - Games Programming  
**Project Type:** Individual coursework project  

## Project Overview
**The Last Door to Home** is a 2D narrative puzzle game with branching endings.

The player takes the role of an astronaut who wakes up in an unfamiliar enclosed space with memory loss. A clue in hand suggests that the mission has already been completed and that opening a certain door will finally lead him home, where his wife is waiting for him.

However, as the player explores the rooms, solves puzzles, and uncovers more fragments of the story, it becomes clear that the obvious door may not be the real way home. The game combines room-based puzzle solving, environmental storytelling, psychological horror, and multiple endings.

## Core Idea
This project focuses on:
- **2D puzzle-based exploration**
- **narrative discovery through environmental clues**
- **multiple endings based on player choices and progression**
- **a psychological horror atmosphere in a small, controlled setting**

The game is designed as a compact but complete experience, with a limited number of rooms and puzzles to keep the project feasible for an individual developer.

## Current Development Stage
This repository is currently in the **pre-production / concept planning** stage.

At this stage, the work mainly includes:
- defining the game concept
- scoping the map and rooms
- outlining the core gameplay loop
- designing branching endings
- evaluating technical feasibility and risks

Implementation has not started yet.

## Planned Gameplay Structure
The current plan is to build a small-scale game with:
- **2 to 3 rooms**
- **environmental clues and interactive objects**
- **puzzle-based progression**
- **one misleading “exit” door and one true way home**
- **three different endings**

### Planned Endings
1. **False Escape / Bad Ending**  
   The player opens the wrong door too early and triggers the monster encounter.

2. **True Escape / Good Ending**  
   The player solves the puzzles, discovers the truth, finds the real exit, and escapes with his wife.

3. **Replacement / Transformation Ending**  
   The player defeats the monster, but becomes part of the cycle and takes its place.

## Design Goals
The project aims to:
- create a clear gameplay loop suitable for a programming-focused coursework project
- balance puzzle mechanics with narrative delivery
- keep the scope small and manageable
- produce enough original code and system design to support the final report
