## Week 2: Structure and System Design

### What I did

- Designed the overall room progression of the base
- Defined the main gameplay phases from waking up to the final escape
- Introduced the idea of real vs false communications as a core narrative mechanic
- Planned the boss encounter as the final challenge of the game
- Decided that player equipment choices can influence the ending
- Refined the scope to focus on one complete vertical slice
- Updated the concept document to better reflect the current story direction

### Problems

- Difficulty balance is still unclear, especially for the boss fight
- Puzzle complexity may currently be too simple
- Need to ensure the gameplay feels like an interactive game rather than only a story sequence
- Some mechanics are defined conceptually but not yet tested in Unity

### Next Step

- Implement basic player movement and collision in Unity
- Build the first playable room (Dormitory or Starting Room)
- Create a simple version of one puzzle (e.g. circuit connection)
- Prototype the boss movement logic
- Begin testing the core gameplay loop in a minimal scene
