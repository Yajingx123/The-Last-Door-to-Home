一、角色设定

怪物阵营：

&#x09;角色：眼球花，巨型食人花

&#x09;目的：占领基地、捉主角（反过来研究人类）



主角阵营：

&#x09;角色：Kian (主角)，Amelia（妻子），Elena（同事1），Jeff(同事2)

&#x09;目的：打开传送门回家



主要角色：

* Kian：普通探索者，乐观稳重，牢记使命，突发事件后一心想要回家
* Amelia：主角的妻子，突发事件后陪在主角身边等着主角意识复苏
* Elena：主角的同事，在外把眼球花带回了基地养殖，误以为无害
* Jeff：主角的同事，突发事件后第一个成功醒来，尝试打电话给Kian，告诉他不要相信这里的一切，不要放弃求生
* 眼球花：植物，普通花朵大小，叶子细长，花中心是眼球，整体各处成肉的质感，在吸收能量石后会变成大型食人花
* 大型食人花：两米至三米高，花朵部分成闭合花苞状，内含致幻粘液，能瞬间将猎物一口包，猎物在它体内因粘液进入幻想状态，若在幻想中丧失求生意志，将再也无法醒来





二、故事主线



主角Kian一伙在充满未知生物的新球进行记录工作，决定返航后，他们将用三颗能源石开启传送门。就在开启传送门的那一刻，同事Elena带上的用于纪念的一束眼球花瞬时将一颗能源石吞食，变成多个巨型食人花，将一伙人吞食入腹。主角Kian因花内粘液进入幻觉世界，在这个世界里，他孤身一人处于基地之中，疑惑重重，完全忘记开启传送门时发生了什么危险。他潜意识里认为——无论如何，必须找到妻子和基地中备用的能源石，再次打开传送门并回家。

为了找到能源石，Kian开始收集手头的线索并破解各处迷局。他用ID卡进入档案室找到了一块能源石，也在卧室破解保险柜密码找到了一块能源石，最后一块却无影无踪。只剩传送室、主控室了，剩下那块如何获得呢？



1. 打开基地大门出去找能源石：各种怪物就在门口蹲着，开门瞬杀 -> 结局一：死亡
2. 再次挖掘基地线索，探索主控室监控和传送门本身构造 -> 故事继续



若直接继续探索传送门，Kian这次选择靠近并尝试了解传送门构造，触摸门构造时，却发现质感不是金属而是肉的质感 -> Boss战，Kian将被困在传送室里，门即怪物，划地为格，Kian需要正确躲避，适时攻击。搏杀开始就致死方休



1. Kian最终被Boss击杀 -> 结局一：死亡
2. Kian杀死了Boss，门不用能源石就开启了，但Kian走进去却来到黑暗中的一块镜子前，他脱下头盔， 看见自己头长满触手的样子，最终认知崩溃 -> 结局二：轮回



想要击杀Boss，Kian必须找到特殊的可穿戴显示仪，有了这份道具Kian在与Boss搏杀的时候能看见Boss心脏的移动位置，从而预判攻击。在击杀Boss的心脏并从中剖出能源石后，Kian就会醒来回到现实世界，发现妻子和同事都围在自己身边，他们刚把Kian从枯萎的花瓣里拖出来，随之显露出来的还有一块能量石。他们遗憾地告知Kian有些同事的意志已经死亡了，成功醒来的不多，本以为除了再次出门寻找能源石外别无选择，还好Kian手中最后一块能源石的能量能够让他们这部分人成功回家 -> 结局三：成功回家
