**一、游戏定位**

类型：2D，剧情，解谜，微恐

适合年龄：16+

立意：生命至上，永不言弃，保持自我



**二、角色设定**



怪物阵营：

&#x09;角色：眼球花，巨型食人花

&#x09;目的：占领基地、捉主角（反过来研究人类）



主角阵营：

&#x09;角色：Kian (主角)，Amelia（妻子），Jeff（同事1），Elena(同事2)

&#x09;目的：打开传送门回家



主要角色：

* Kian：普通探索者，乐观稳重，牢记使命，突发事件后一心想要回家
* Amelia：主角的妻子，突发事件后陪在主角身边等着主角意识复苏
* Jeff：主角的同事，在外把眼球花带回了基地养殖，误以为无害
* Elena：主角的同事，突发事件后第一个成功醒来，尝试打电话给Kian，告诉他不要相信这里的一切，不要放弃求生
* 眼球花：植物，普通花朵大小，叶子细长，花中心是眼球，整体各处成肉的质感，在吸收能量石后会变成大型食人花
* 大型食人花：两米至三米高，花朵部分成闭合花苞状，内含致幻粘液，能瞬间将猎物一口包，猎物在它体内因粘液进入幻想状态，若在幻想中丧失求生意志，将再也无法醒来





**三、故事主线**



主角Kian一伙在充满未知生物的新球进行记录工作，决定返航后，他们将用三颗能源石开启传送门。就在开启传送门的那一刻，同事Jeff带上的用于纪念的一束眼球花瞬时将一颗能源石吞食，变成多个巨型食人花，将一伙人吞食入腹。主角Kian因花内粘液进入幻觉世界，在这个世界里，他孤身一人处于基地之中，疑惑重重，完全忘记开启传送门时发生了什么危险。他潜意识里认为——无论如何，必须找到妻子和基地中备用的能源石，再次打开传送门并回家。

为了找到能源石，Kian开始收集手头的线索并破解各处迷局。期间将受到或者或假的留言通讯。他用在卧室破解保险柜密码找到了一块能源石。只剩传送室、主控室了，剩下两块如何获得呢？



1. 打开基地大门：各种怪物就在门口蹲着，开门瞬杀 -> **结局一：死亡**
2. 再次挖掘基地线索，主控室中能够获取一颗备用能源石，再继续探索主控室监控和传送门本身构造 -> 故事继续



若直接继续探索传送门，Kian这次选择靠近并尝试了解传送门构造，触摸门构造时，却发现质感不是金属而是肉的质感 -> Boss战，Kian将被困在传送室里，门即怪物，划地为格，Kian需要正确躲避，适时攻击。搏杀开始就致死方休



1. Kian最终被Boss击杀 -> **结局一：死亡**
2. Kian杀死了Boss，门不用能源石就开启了，但Kian走进去却来到黑暗中的一块镜子前，他脱下头盔， 看见自己头长满触手的样子，最终认知崩溃 -> **结局二：轮回**



想要击杀Boss，Kian必须找到特殊的可穿戴显示仪，有了这份道具Kian在与Boss搏杀的时候能看见Boss心脏的移动位置，从而预判攻击。在击杀Boss的心脏并从中剖出能源石后，Kian就会醒来回到现实世界，发现妻子和同事都围在自己身边，他们刚把Kian从枯萎的花瓣里拖出来，随之显露出来的还有一块能量石。他们遗憾地告知Kian有些同事的意志已经死亡了，成功醒来的不多，本以为除了再次出门寻找能源石外别无选择，还好Kian手中最后一块能源石的能量能够让他们这部分人成功回家 -> **结局三：成功回家**

**五、游戏流程**



**开局动画：开篇交代主角记忆和当前局势【1min】**

1. 你和你的同事们工作在一个危险并充满奇怪生物的世界，那里危险、荒凉，栖息着无法被准确定义的异星生物（图片1）
2. 经过漫长的探索，你们终于完成了研究。所有资料都已成功传回总部。（图片2）
3. 然后，你们等来了那条消息：你们终于可以回家了。（图片3）
4. 你和妻子站在传送门前。你们一起按下了启动键。(图片4)
5. ……那就是你记忆中的最后一幕。（无图片，全黑）
6. 你醒来时，身边空无一人。没有同事，没有妻子，也没有任何回应。脚边躺着你的手札。最后一句写着：“Finally, we can go home.”（图片5）
7. 尽管疑问重重，你的心中只有一件事——回家（图片6）



**阶段一：在卧室中迅速弄清局势 【6min】**

* 位置\&起点：宿舍里
* 自带物品：自己的手札，传呼机
* 收集物品：室友Jeff的ID卡（解锁资料室）、Jeff的手稿（眼球花资料）
* 观察物品：

  * 室友Jeff的几张手稿（体现Jeff的人设和世界观）
  * Jeff手稿（记录着Jeff来这儿的第一天，日期即为保险箱密码）
  * 有眼球花的花瓶（暗示怪物早已潜伏）
  * 墙上代替窗户的画（基地的压抑和对回家的渴望）
  * Jeff的保险柜（去找Jeff的重要日子）-> **得到第一块能源石**
  * 传呼机：可播放妻子的留言（交代他们都出去了，事情很复杂一时不好交代，主角要是醒来就给他们打电话），但向外传唤呼叫不通 -> 出门前往走廊
* 情绪变化：开局疑惑、茫然 -> 听到留言后有了希望 -> 疑惑、感到奇怪



**阶段二：探索地图——走廊、大门、电梯、资料室 【10min】**

* 位置：宿舍走廊
* 可选去向：

  * 当前位置：剩余两扇宿舍门，均无人
  * 走廊左边：通往基地大门（主角潜意识里暂时不会出去）
  * 走廊右边：通往电梯 -> 前往负一楼
  * 负一楼走廊中央：电梯
  * 负一楼走廊左边：资料室（用Jeff的ID卡解锁）
  * 负一楼走廊右边：主控室（不通，需要更高权限的ID卡）
* 观察物品：

  * 基地大门旁的员工守则告示（“基地不可无人值守”）
  * 基地大门旁的有眼球花的花瓶（暗示正在观察的怪物）
  * 主控室门口旁有眼球花的花瓶（暗示正在观察的怪物）
  * 资料室眼球花资料（眼球花可用于估算时间的特性）
* 剧情触发：

  * 从宿舍到了电梯：同事Elena的第一通留言（信号不好，那边怎么了）
* 情绪变化：疑惑，感到诡异



**阶段三：基地去与留的抉择**

* 位置：资料室 -> 大门/主控室
* 剧情触发：

  * 出资料室：妻子的第二通留言（引导Jeff叛逃一事）
  * 过三十秒：妻子的第三通留言（引导Kian出门）\& 同事Elena的第二通留言（制造冲突，Kian为两边的局势而感到困惑）-> 主角前往基地大门

    * 若前往基地大门 -> 主角因员工守则告示而犹豫 -> **抉择：出门（结局一：死亡）**【4min】/先搞明白基地发生了什么再出门 -> 主角前往主控室
    * 若前往主控室 -> 妻子的第四通留言（她迫切需要Kian出来帮她）+ 同事的第三通留言（妻子好像发生了什么事）-> 分水岭抉择：先出门看看**（结局一：死亡）**【8min】/必须先确认主控室情况 -> **阶段四**
* 情绪变化：

  * 听到妻子第三通留言后 -> 怀疑，矛盾，气愤 -> 平静，不理解
  * 听到Elena第二通留言后 -> 困惑，紧张，担忧
  * 听到妻子的第四通留言后 -> 诡异，犹豫
  * 听到Elena第三通留言后 -> 焦急





**阶段四：主控室真相**

* 位置：主控室门口 -> 主控室 -> 传送室门口
* 观察物品：

  * 主控室大门（敲门无回应）
  * 主控室门口刷卡机（主角和Jeff的ID卡都没有用，权限不足）
  * 主控室门口旁有眼球花的花瓶 -> 砸碎刷卡机外壳 -> **电路连接修复puzzle（easy, 1min）** -> 进入主控室
  * 主控室内：

    * 柜子里（备用能源石）-> **得到第二块能源石**
    * 装备墙 ，均可选 (但选得越多越容易拖慢行动速度) ->

      * 小刀（对Boss单次伤害变大）**（导向结局二：轮回）**
      * 高级防御服（能够减少单次掉血量）**（导向结局二：轮回）**
      * 异象扫描仪（能看到Boss真正的弱点）**（有概率导向结局三：成功回家）**
    * 传送室大门（坚硬，不可暴力破解，必须有更高权限的ID卡）
    * 四台电脑（不同的管理层同事的电脑）->

      * 控制监控的电脑 -> 在电脑系统模拟界面找到正确的日期文件 -> 调取 -> **监控器动画**（显示那天大家齐聚在传送门前，Jeff的眼球花束在碰到了能源石后变成巨型食人花，盘踞了整个传送室，有些人被吞入了食人花，然后监控器被损坏了，动画结束）
      * 有读卡器的电脑 -> 升级ID卡权限（触发过传送室门禁才有这个选项）
* 触发剧情：

  * 看完监控并选择了一个装备后：Elena第四通留言（妻子肯定出了事，希望主角能够回到他们身边）-> 升级ID卡 -> 进入传送室 -> **阶段五**
* 情绪变化：

  * 看完监控：恍然大悟，惊恐，仍有少量困惑
  * 听完Elena第四通留言：急躁，强制镇定，鼓起勇气，渴望回家

位置：传送室内


**六、真假留言系统**



**妻子的电话（假）：**

目的：把主角骗出基地大门，怪物们在门口蹲着，开门瞬杀

过程：误导主角去聆听心中不好声音，使主角误以为这一切都是Elena（把眼球花当作无害生物带入基地的同事）想要私吞功劳而有意造成的，来推动主角离开基地

（Elena是专门采集标本的人员，擅长生化，平日大胆、好奇又古怪，若是她有手段在回去的那一刻迷晕所有人也不是不可能）

妻子在电话中还说她和其余同事全都出去寻找可用的的能源了，走前见主角迟迟不醒才先把主角留在基地中，现在主角醒了，那就快出来跟他们一起找能源石吧



1. Kian, 你在吗？你能听到我的声音吗 -> 主角开始有继续探索的希望了
2. 我们醒来时只有Elena不在，三颗能源石也都没了，传送门有使用过的痕迹...当下想要回家，我们只能重新收集能源石了 ->  主角气愤 -> 拿走Elena的手札试图找到缘由
3. Kian，我们都在外面找能源石，现在是白天，很安全，如果你听见了，快来加入我们 -> 主角想出门但回忆起基地培训手册，犹豫了 -> 去主控室看还有没有人
4. 主控室那边不用管，一切正常，你赶紧过来就好 -> 主角疑惑，主控室敲门也没人应啊 -> 收集线索 -> 成功进入主控室
5. Kian，我们遇险了！我的ID卡丢失了，你快开门来帮我！-> 主角听到同事的电话了，陷入两头疑环节





**同事Jeff的电话（真）：**

过程：Jeff是第一个成功挣脱食人花的人，他救出的同事有的还在幻境中，有的救出来也意志消亡了，唯独把主角吞食的食人花特别大（因为是蕴含能源石的那一株）

他没法把主角弄出食人花，于是一直在外面呼唤主角，试图帮助主角挣脱幻境

1. Kian， \*\*能听到\*\*声音吗？你千万不要\*\*你看\*\*那些\*\*！快\*\*来！（你千万不要相信你看到的那些！快醒来！）
2. 我们\*\*是Elena的眼球花\*\*\*大家都\*\*\*！
3. 我们把\*\*Elena成功\*出了\*\*\*没想到她最终还是\*\*\*（我们把Elena成功救出了食人花，但没想到她最终还是意志死亡了）-> 主角可能以为Elena真自己背叛所有人
4. 你的妻子她暂时还没\*\*来，你快\*\*来，她需要你！（你的妻子她暂时也还没醒来，你快醒过来，她需要你！）
5. 快醒来吧，Kian，如果没有你，你的妻子醒过来会崩溃的 -> 主角震惊且疑惑，但局势紧张，必须选择是否出基地大门救妻子，还是仍然留在基地





**资料（真）：**

眼球花资料：眼球部分在白天会闭上，随着天色变暗逐渐“睁眼”，晚上全睁，可简单用来估测时间

Elena的笔记：这个星球的同种族们仿佛共用一副神经系统，一朵眼球花被灼烧，附近所有的眼球花都会有反应 -> 解释了基地内的眼球花能够把信息传递给外面的怪物们

Elena的笔记：记录着她发现眼球花的那一天，她猜测，会不会也有嘴唇花、鼻子花呢？这个星球的生物都像是认知中一部分事物拼凑出来的，她十分期待发现更多的生物

主角的基地培训手册：除非放弃基地，任何情况不得无人值守



**矛盾点：**

1. Elena在主角的记忆中不是那种人
2. 培训手册的原则之一是，基地不可无人值守，就算Elena独自逃走，也不至于所有人都出动去寻找能源，让基地空无一人
3. 走廊的眼球花全睁开，但妻子却说外面是白天
4. 同事说Elena已经死了，妻子说Elena自己逃走了
5. 同事说妻子还没醒 -> 主角可能感到疑惑想那刚才妻子不是一直在跟我说话吗，从而质疑全局，或者以为妻子是遇险醒不过来了，想要赶紧赶过去
6. 如果Elena要背叛所有人，那为什么没有把保险箱里的能源石带走
